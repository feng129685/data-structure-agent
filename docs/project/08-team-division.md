# 团队分工建议

下面按 4-6 人小组设计。如果人数更多，可以把每一项再拆细。

## 1. 4 人分工

| 角色 | 主要任务 | 产出 |
|---|---|---|
| 产品/汇报负责人 | 定方案、写汇报、准备演示 | 项目方案、展示脚本、PPT |
| 平台搭建负责人 | 在智能体平台创建智能体、配置工作流 | 可用智能体链接 |
| 知识库负责人 | 整理课程资料、例题、错题 | 知识库文档 |
| 测试优化负责人 | 准备测试问题、记录问题、调提示词 | 测试表、优化记录 |

## 2. 5 人分工

| 角色 | 主要任务 | 产出 |
|---|---|---|
| 项目负责人 | 控制进度、对接老师、统一方案 | 任务看板、最终方案 |
| 智能体配置负责人 | 主提示词、角色设定、开场白 | 智能体配置 |
| 工作流负责人 | 问题分类、分支流程、回答整理 | 工作流图 |
| 知识库负责人 | 课程资料和题库整理 | 知识库 |
| 测试与演示负责人 | 测试用例、演示脚本、录屏 | 测试报告、演示材料 |

## 3. 6 人分工

| 角色 | 主要任务 | 产出 |
|---|---|---|
| 产品负责人 | 需求、方案、范围控制 | 项目方案 |
| 平台负责人 | 创建智能体、发布链接 | 平台原型 |
| 提示词负责人 | 主提示词和子 Agent 提示词 | 提示词文档 |
| 知识库负责人 | 课程资料清洗、分组上传 | 知识库 |
| 测试负责人 | 测试集、问题记录、迭代建议 | 测试报告 |
| 汇报负责人 | PPT、演示脚本、口头表达 | 汇报材料 |

## 4. 两周推进计划

### 第 1 天

- 确定平台
- 确定首版范围
- 确定小组分工

### 第 2-3 天

- 整理课程知识库
- 完成主智能体提示词
- 搭建基础智能体

### 第 4-5 天

- 搭建问题分类和分支流程
- 加入题目拆解、知识讲解、代码诊断能力

### 第 6-7 天

- 加入过程可视化和小测复习
- 跑第一轮测试

### 第 8-10 天

- 根据测试结果优化提示词和知识库
- 准备演示案例

### 第 11-12 天

- 做最终演示脚本
- 整理项目亮点和不足

### 第 13-14 天

- 彩排
- 补充截图、录屏和汇报材料

## 4.1 每日同步模板

每天同步时，每个人只需要说清楚三件事：

| 问题 | 示例 |
|---|---|
| 今天完成了什么 | 上传了链表和二叉树知识库，跑了 8 条测试 |
| 遇到什么问题 | 二叉树层序遍历回答有时忘记队列变化 |
| 明天准备做什么 | 补提示词约束，复测 T06、T12 |

## 4.2 交付验收口径

| 负责人 | 最低交付标准 | 验收方式 |
|---|---|---|
| 项目/汇报负责人 | 能讲清项目定位、首版范围、创新点和不做什么 | 按 `06-demo-script.md` 彩排 |
| 平台搭建负责人 | 智能体可访问，知识库和主提示词已配置 | 小组成员能打开链接测试 |
| 提示词负责人 | 主提示词和 5 个子 Agent 提示词可复制使用 | 用 5 类问题各测 1 条 |
| 工作流负责人 | 问题分类、知识库检索、分支处理、最终整理能跑通 | 用 T01-T10 验收 |
| 知识库负责人 | 至少 5 个主题，每个主题有定义、操作、复杂度、易错点、例题 | 随机抽问 10 条 |
| 测试负责人 | 至少 20 条测试记录，含失败原因和修改建议 | 提交测试表 |

## 5. 最小交付物

至少交付这些内容：

- 一个可访问的智能体链接
- 一份项目方案
- 一份知识库材料
- 一份测试用例表
- 一个完整演示案例
- 一份后续迭代计划

## 6. 老师可能会问的问题

### 这个智能体和普通 ChatGPT 有什么区别？

它接入了课程知识库，并按数据结构学习场景设计了题目拆解、过程可视化、代码诊断和小测反馈，不只是泛泛聊天。

### 你们怎么保证回答准确？

我们会优先使用老师的讲义和课程资料，并准备测试用例持续优化。对于知识库没有覆盖的内容，智能体会明确提示不是课程资料原文。

### 能不能真的运行代码？

首版主要做静态诊断，不接真实代码运行。后续可以接入代码沙箱或在线判题服务。

### 为什么先做这几个章节？

栈、队列、链表、二叉树和图遍历是数据结构课程中最核心、最适合演示结构变化的内容，适合作为首版范围。

### 你负责什么？

你可以说：

我可以负责项目方案设计、提示词配置、知识库整理和测试优化，也可以参与平台搭建。我希望先把一个能演示的最小版本做出来，再根据老师反馈继续扩展。

## 7. 需要向老师确认的问题

建议见老师或组会时确认这几个问题：

1. 老师希望我们必须使用哪个平台，还是可以自由选择？
2. 首版演示更希望看哪个章节：栈/队列、链表、二叉树还是图？
3. 课程 PPT、实验指导书、作业题能否作为知识库材料？
4. 是否允许我们做一个本地 HTML 原型辅助展示？
5. 老师更看重课堂演示、课后答疑，还是作业辅助？
