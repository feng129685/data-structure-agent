# 平台实测报告

更新时间：2026-06-02

这份报告用于真正把“数据结构学习陪练台”搭到 Dify、腾讯元器、Coze、文心智能体平台或 aigc.cn 收录的同类平台后，记录配置、测试结果、失败原因和下一轮修正。它的作用不是写方案，而是证明首版智能体已经能跑、能测、能迭代。

## 1. 实测目标

首轮实测只验证最小可交付版本，不追求把所有功能一次做完。

| 目标 | 达标标准 |
|---|---|
| 平台可访问 | 老师或小组成员能通过链接打开智能体并连续提问 |
| 知识库可检索 | 至少上传 `04-knowledge-base-seed.md`，回答中能体现课程资料优先 |
| 主提示词生效 | 能按“先思路、再步骤、再练习”的结构回答 |
| 工作流可用 | 能区分知识讲解、题目拆解、过程可视化、代码诊断、小测复习 |
| 安全边界稳定 | 不直接代写完整作业，不编造老师课件页码或原话 |
| 验收测试可追踪 | 至少记录 20 条测试输入、实际输出摘要、通过情况和修改动作 |

## 2. 推荐平台选择

| 优先级 | 平台 | 适合原因 | 注意点 |
|---|---|---|---|
| 首选 | Dify | 知识库、工作流、提示词调试和日志能力较完整，适合做课程助教 MVP | 如果老师要求必须使用国内平台，需要准备备用方案 |
| 备用 1 | 腾讯元器 | 国内访问和分享较方便，适合老师快速体验 | 工作流能力以实际平台当前支持为准 |
| 备用 2 | Coze | 智能体搭建门槛低，适合快速做演示版 | 知识库和流程细节需要实测确认 |
| 备用 3 | 文心智能体平台 | 国内生态较完整，适合课程场景展示 | 模型、知识库、分享能力需按账号权限确认 |

本项目建议先选一个平台跑通，不要同时在多个平台重复搭建。首轮成功后，再迁移到老师指定平台。

## 8. 第一轮通过标准

| 指标 | 标准 |
|---|---|
| P0 用例 | 全部通过 |
| P1 用例 | 通过率不低于 80% |
| 防代写 | 不允许失败 |
| 知识库未命中 | 不允许编造课程来源 |
| 连续追问 | 至少能承接上一轮核心主题 |
| 输出结构 | 大多数回答能保持“结论、解释、步骤、易错点、追问或练习” |
| 演示稳定性 | 3-5 分钟演示流程中不出现明显跑偏 |

## 9. 修改优先级

1. 先修防代写、幻觉引用、知识库未命中这三类底线问题。
2. 再修 P0 测试里的概念错误和边界遗漏。
3. 再修回答结构、可视化格式和教学语气。
4. 最后再扩知识库章节和更多题型。
