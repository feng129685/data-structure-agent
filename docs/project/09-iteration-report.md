## 1. 本轮目标

把“数据结构学习陪练台”从方案材料进一步推进到可落地版本：

- 老师能快速看懂当前进度。

- 提示词、知识库、测试用例有更明确的验收口径。
- 本地原型更适合课堂演示和移动端展示。

## 3. 原型 UI 优化点

- 顶部“发布”改为“生成演示”，更贴合课堂展示语境。
- 右栏“工作流与测试”改为“可视化与练习”，标签改为“步骤 / 练习 / 掌握度 / 记录”。
- 移动端左侧资料栏从 hover 展开改为显式“资料”按钮，并同步 `aria-expanded`。
- 移动端右侧面板增加独立“展开可视化 / 收起可视化”按钮，避免把含有标签按钮的面板头整体伪装成按钮。
- 中间对话区新增智能体工作区，借鉴热门智能体的项目资料、学习画布、工具状态、引用来源和建议追问模式。
- 参考个人网站 `example.com` 的视觉气质，将整体风格调整为浅纸色、墨色侧栏、细边线、低饱和、安静笔记/档案式界面。
- 新版首页只保留项目定位、四个入口和少量状态指标；对话、可视化、材料、验收分别进入 Coach、Lab、Docs、Test 页面，避免所有元素挤在同一屏。
- 首页文案明确“面向数据结构课程的学习陪练台，不是普通聊天机器人”，右侧用链表/树的细线节点图作为课程身份信号。
- 将原型中的青绿、橙色状态反馈统一收束为黑、米白、灰褐、低饱和棕灰，避免和个人网站风格冲突。
- 首页新增公开入口按钮、开始演示按钮、验收入口按钮，老师打开页面后可以直接按交付流程浏览。
- 首页新增交付状态条和交付检查区，明确公开地址、材料包、5 个课程模块、20 条验收用例和下一步真实平台接入。
- 首页从“项目交付页”调整为“学习仪表盘”，突出当前学习重点、下一步动作、针对小测和教师验收视角。
- 入口命名从学习陪练 / 可视化实验 / 项目材料 / 平台验收，调整为 AI 学习陪练 / 结构实验室 / 课程资料库 / 教师验收台。
- 移动端隐藏旧顶部工具栏，只保留黑色导航条和分层入口，减少第一眼信息负担。
- 右侧标签补齐 `tablist` / `tab` / `tabpanel` 语义、`aria-selected` 和键盘方向键切换。
- 移动端左侧资料栏折叠时同步 `aria-hidden`、`inert` 和子控件 `tabindex`，避免键盘焦点进入不可见内容。
- 顶部标题改为页面 `h1`，搜索、对话、动态可视化输入补充 `name`、`autocomplete`、程序化 label 和 `aria-describedby`。
- 可视化控制按钮、场景按钮、主题按钮和弹窗关闭按钮统一提升到 44px 以上触达尺寸。
- Toast 增加 `aria-live="polite"`。
- 主题切换按钮增加动态 `aria-label`。
- 主题偏好现在会按 `light` / `dark` 原值持久化，刷新页面不会反向切回浅色。
- 课堂演示弹窗增加 `aria-hidden` 状态同步、Tab 焦点圈定、Esc 关闭和关闭后回到触发按钮。
- 桌面端工作区恢复顶部工具栏，首页仍隐藏工具栏以保持简洁。
- 陪练页中间对话区改成学习记录流：建议区变为透明摘要线，助教回答去掉实心卡片，元信息从胶囊标签降为小号注释。
- Lab 结构实验室移除大面积蓝灰视觉块：顶部场景 chip、实验 tab、操作按钮和复杂度图表统一改成黑 / 米白 / 灰褐的轻量状态表达。
- 顶部全局工具栏不再显示，避免与左侧主导航和页面标题重复；页面保留左侧导航、页面标题、场景切换和主体内容。
- 增加 `prefers-reduced-motion` 兜底，并移除当前场景按钮的无限装饰脉冲动画。

- `11-platform-copy-pack.md` 把真正登录平台时要复制的名称、简介、开场白、快捷问题、主提示词、节点配置和 10 条烟测问题集中到一处。
