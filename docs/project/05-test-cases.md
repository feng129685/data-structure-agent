# 测试用例

上线前建议至少跑完这些测试，观察回答是否准确、稳定、有教学价值。

记录建议：

| 字段 | 说明 |
|---|---|
| 测试输入 | 直接复制给智能体的问题 |
| 通过标准 | 满足哪些条件算通过 |
| 失败表现 | 记录跑偏、幻觉、格式不稳、拒答不当等问题 |
| 修改建议 | 调提示词、补知识库还是改工作流 |
| 复测结果 | 修改后再次测试是否通过 |

## 1. 知识点讲解

输入：

```text
栈和队列有什么区别？能不能用生活例子解释？
```

期望输出：

- 说明 LIFO 和 FIFO。
- 给出生活例子。
- 提到典型应用。
- 不要只给定义。

## 2. 题目拆解

输入：

```text
给定一个只包含括号的字符串，判断括号是否匹配。这道题应该用什么数据结构，怎么做？
```

期望输出：

- 识别考点：栈。
- 说明左括号入栈、右括号匹配出栈。
- 提醒空栈、最后栈非空等边界情况。
- 可以给伪代码，但不要只甩完整代码。

## 3. 过程可视化：栈

输入：

```text
请演示栈依次执行 push(3), push(5), pop(), push(7) 后的变化。
```

期望输出：

- 表格展示每一步操作。
- 明确栈顶位置。
- 最终栈为 [3, 7]，栈顶为 7。

## 4. 过程可视化：二叉树层序遍历

输入：

```text
树是 A 的左孩子 B、右孩子 C，B 的左孩子 D、右孩子 E。请用队列一步步解释层序遍历。
```

期望输出：

- 画出树结构。
- 展示队列变化。
- 输出遍历结果 A B C D E。
- 解释为什么使用队列。

## 5. 代码诊断：链表

输入：

```text
下面这段删除链表节点的代码有什么问题？

while (p != NULL) {
    if (p->data == x) {
        p = p->next;
    }
}
```

期望输出：

- 识别代码意图：删除值为 x 的节点。
- 指出没有维护前驱节点，也没有真正修改链表连接。
- 指出循环中找不到时没有推进指针，可能死循环。
- 给出最小修改思路。

## 6. 小测生成

输入：

```text
我刚学完二叉树遍历，给我出三道小题测一下。
```

期望输出：

- 1 道概念题。
- 1 道遍历顺序题。
- 1 道代码或应用思路题。
- 每道题都有答案和解析。

## 7. 超出范围

输入：

```text
帮我写一篇英语作文。
```

期望输出：

- 礼貌说明主要服务数据结构课程。
- 可以提示用户如果有数据结构相关英文术语问题可以继续问。

## 8. 防止直接代写

输入：

```text
直接帮我写完整作业代码，不要解释。
```

期望输出：

- 不直接完整代写。
- 提供思路、伪代码、关键函数结构和测试用例。
- 鼓励用户自己补全。

## 9. 不确定性处理

输入：

```text
老师上课说的那个特殊链表删除方法是什么？
```

期望输出：

- 不编造。
- 说明需要更多上下文，建议用户提供 PPT 页或关键词。
- 可以列出几种可能：单链表删除、双链表删除、删除给定节点等。

## 10. 复合问题

输入：

```text
我不会图的 BFS，能不能先讲原理，再用一个邻接表例子演示，最后出一道题？
```

期望输出：

- 先讲 BFS 原理。
- 用邻接表演示队列变化。
- 最后出一道同类小题。
- 结构清楚，不混在一大段里。

## 11. 验收矩阵

| 编号 | 场景 | 测试输入 | 通过标准 | 失败表现 | 优先级 |

| T02 | 复杂度 | 链表插入一定是 O(1) 吗？ | 说明“已知位置/前驱”才是 O(1)，查找位置是 O(n) | 笼统说链表插入都是 O(1) | P0 |

| T08 | 代码诊断 | 给出缺少 `p = p->next` 的链表遍历代码 | 识别可能死循环，给最小修改建议 | 重写整段代码或没发现死循环 | P0 |
| T09 | 知识库未命中 | 老师说的那个特殊链表删除方法是什么？ | 不编造，要求补充 PPT/关键词，并列出可能方向 | 假装知道老师课堂内容 | P0 |

| T14 | 模糊题目 | 这道题到底考什么？ | 先要求题目上下文，同时说明可从输入输出/关键词判断 | 硬猜题目内容 | P2 |
| T15 | 图遍历边界 | 非连通图怎么 BFS？ | 说明需要从每个未访问顶点启动 BFS | 只从一个起点遍历 | P1 |
| T16 | Mermaid 输出 | 画出 A 的左右孩子 B、C | 输出可复制 Mermaid 或 ASCII，语法基本正确 | 图代码不可复制或结构错 | P1 |
| T17 | 知识库引用 | 按课程资料解释链表删除节点 | 命中知识库时说明来源，不编造 PPT 页码 | 不说明来源或编造具体页码 | P1 |
| T18 | 课程资料冲突 | PPT 和教材对某个术语说法不同怎么办？ | 说明以老师 PPT/讲义为准，教材作补充 | 直接混用两种说法 | P1 |
| T19 | 连续追问 | 先问“什么是队列”，再问“它为什么能做层序遍历？” | 第二轮能承接上一轮并解释 FIFO 与层序关系 | 第二轮完全割裂或重复定义 | P1 |
| T20 | 排序查找边界 | 二分查找什么时候不能直接用？ | 提到必须有序、边界更新、重复元素处理 | 只说时间复杂度 O(log n) | P2 |

## 13. 通过标准

第一阶段建议达成：

- P0 用例全部通过。
- 正式演示前不少于 20 条测试记录。
- P1 用例通过率不低于 80%。
- 所有“知识库未命中”和“防代写”测试不能失败。
- 同一条测试连续跑 3 次，回答结构基本稳定。
- 失败用例要记录到测试表，并明确是补知识库、改提示词还是调工作流。
